# Cyberpunk Fan Club

Fan club website about the Cyberpunk universe (Cyberpunk 2077, Cyberpunk: Edgerunners and the tabletop games).
Group project for **CSC31005 Practical IT Skills**, Taylor's College, August 2026 semester.

Open `index.html` in a browser to view the site.

## Pages

| File | Page |
|---|---|
| `index.html` | Home: welcome, purpose of the club, recent updates, links to all pages |
| `about-us.html` | About Us: group members (photos, names, student IDs, profiles), in progress |
| `characters.html` | Characters from Cyberpunk: Edgerunners |
| `Background.html` | Background: the world of Night City |
| `events.html` | Upcoming events (table with dates, times, locations, descriptions) |
| `gallery.html` | Gallery of Cyberpunk images (grid layout) |
| `more.html` | Library of related games, anime and tabletop games |
| `join_us.html` | Join Us: membership registration form |
| `submit.html` | Success page shown after the form is submitted |

## Folders

```
css/
  style.css            main style sheet used by every page
  images/              gallery and event images
    characters/        character photos used on characters.html
```

All pages share the same header, navigation bar and footer.
